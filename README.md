# TEDxNITK Surathkal – Front Page Redesign

**Live site:** https://aravhegde478.github.io/Tedx_2026_Recs_task/

Responsive redesign of the TEDxNITK Surathkal landing page in TEDx red, black and white, built with plain HTML, CSS and JavaScript.

## Highlights
- Hero with interactive embers that follow the cursor and burst on click
- Live countdown, animated stat counters and 3D tilt cards
- Speaker flip cards, scrolling marquee, cursor glow and scroll progress bar
- Registration form with validation and NITK / non-NITK conditional fields
- Mobile menu, keyboard focus styles and reduced-motion support

## Run locally
Open `index.html` in a browser, or use the optional Flask server:

    pip install -r requirements.txt
    python app.py

Then visit http://127.0.0.1:5000.

## Project files
- `index.html` – page structure
- `style.css` – theme, layout and animations
- `script.js` – embers, countdown, counters, tilt, flip cards, form
- `app.py` – optional local preview server
